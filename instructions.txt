Python Senior BE Assignment

Thank you for moving forward in our selection process. As part of the next stage, we would like to assign you a technical project to evaluate your proficiency in designing and implementing RESTful APIs, handling asynchronous requests, and managing relevant business logic.

Technical Assignment

Your task is to develop a RESTful API server with the following key functionalities:

1. Request OpenAI Chat per user (user as a simple entity - not using multiple OpenAI users).
2. The requests should be handled asynchronously.
3. A service that creates these requests and enforces the following:
   - Users are not allowed to mention the names of other users in their requests.
   - Once a user exceeds 3 times mentioning other users it will be blocked (and won't be able to make requests anymore)

Management and Design Assignment

Design a mechanism and break it into tasks for your development team of the following:

1. Unblock user functionality on demand.
2. Unblock the user after a period of time.

Deliverables:

- Your code submission should include documentation outlining your approach, design decisions, and any relevant details to guide reviewers.
- Note: We allow using any tool available, but we expect an cloud native enterprise grade code I can run in my K8s cluster
